# 刚度阻尼三档配置

`config/` 下新增三份完整的 UR10e 真机控制器参数文件，均使用 `base → tool0` 的绝对目标位姿。它们只在六维刚度和阻尼上分档；每个方向的阻尼数值按 $D_i \approx 2\sqrt{K_i}$ 取三位小数。这是把等效质量归一化为 1 的调参起点，不能视为实际机械臂各方向的严格临界阻尼。

| 档位 | 配置文件 | $K_{xyz}$ | $D_{xyz}$ | $K_{rot}$ | $D_{rot}$ |
| --- | --- | ---: | ---: | ---: | ---: |
| 低 | `ur10e_cartesian_impedance_low.yaml` | 100 | 20.0 | 8 | 5.657 |
| 中 | `ur10e_cartesian_impedance_medium.yaml` | 300 | 34.641 | 20 | 8.944 |
| 高 | `ur10e_cartesian_impedance_high.yaml` | 700 | 52.915 | 50 | 14.142 |

六维数组顺序均为 `[x, y, z, rx, ry, rz]`。三档均沿用生成时真机基础配置中的其他参数：`max_pose_error=[0.20,0.20,0.20,0.5,0.5,0.5]`、`max_wrench=[40,40,40,4,4,4]`、`max_torque=[60,60,60,30,30,30]`、`reference_filter_alpha=1.0`。因此三档文件当前**不进行目标位姿低通**，绝对目标会直接进入误差计算。三层限幅依次作用于位姿误差、任务 wrench 和最终关节力矩；`max_pose_error` 不限制目标可达距离。若改动基础配置文件，三档文件不会自动同步，需要逐份核对。

例如静态平移误差为 0.20 m 时，高档的弹簧项为 140 N，但 `max_wrench` 会将该方向最终任务力裁剪到最多 40 N；阻尼项也参与裁剪前的计算。高档更容易触及 wrench 限幅，不应只凭 $D=2\sqrt K$ 判断真机响应。

`standalone_real.launch.py` 默认加载原有的 `ur10e_ft300_cartesian_impedance.yaml`。选择新档位时，先在终端 1 启动驱动并让初始轨迹控制器保持 inactive，再在终端 2 用指定参数文件加载本控制器。以下命令以中档、关闭夹爪和 FT300 为例：

终端 1：

```bash
source /opt/ros/jazzy/setup.bash
source /ros2_ws/install/setup.bash
ros2 launch ur10e_robotiq_ft_description real_bringup.launch.py \
  robot_ip:=169.254.138.15 \
  ft_sensor_ftdi_id:=ttyUSB2 \
  ft_sensor_use_fake_mode:=true launch_gripper:=false launch_rviz:=false \
  use_cartesian_impedance:=false activate_joint_controller:=false
```

终端 2：

```bash
source /opt/ros/jazzy/setup.bash
source /ros2_ws/install/setup.bash
ros2 run controller_manager spawner cartesian_impedance_controller \
  --controller-manager /controller_manager \
  --param-file /ros2_ws/src/cartesian_impedance_controller/config/ur10e_cartesian_impedance_medium.yaml
ros2 control list_controllers -c /controller_manager
```

选低档或高档时，把文件名末尾的 `medium` 改为 `low` 或 `high`。`robot_ip` 要使用实际机器人地址。确认 `cartesian_impedance_controller` 为 `active`，并按[使用方式](03_使用方式.md)检查六关节 effort 接口后再发送目标。切换档位前先停止当前控制器；不要同时激活其他运动控制器。
