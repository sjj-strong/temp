# 7. 默认笛卡尔阻抗启动与固定 Z 轴测试

`ur10e_robotiq_ft_description` 的 `real_bringup.launch.py` 默认在真机驱动就绪后加载并激活
`cartesian_impedance_controller`。官方 `scaled_joint_trajectory_controller` 会保留为 inactive，
不会和笛卡尔阻抗控制器争用六个关节的命令接口。

```bash
ros2 launch ur10e_robotiq_ft_description real_bringup.launch.py \
  robot_ip:=169.254.138.15 \
  ft_sensor_ftdi_id:=ttyUSB2 \
  gripper_com_port:=/dev/ttyUSB0
```

启动完成后必须确认：

```bash
ros2 control list_controllers -c /controller_manager
```

输出中应为 `cartesian_impedance_controller ... active`，且
`scaled_joint_trajectory_controller ... inactive`。若需要恢复原先官方启动行为，显式设置：

```bash
ros2 launch ur10e_robotiq_ft_description real_bringup.launch.py \
  use_cartesian_impedance:=false
```

## 固定测试命令

在另一个终端执行：

```bash
source /opt/ros/jazzy/setup.bash
source /ros2_ws/install/setup.bash
ros2 run cartesian_impedance_controller move_base_z_005
```

该工具读取 `/tcp_pose_broadcaster/pose`，并只发布一次 `base` 坐标系下的相对位移：

```text
Δx = 0 m, Δy = 0 m, Δz = +0.05 m
Δ姿态 = 0
```

它不会接受位置、姿态或位移参数；若当前 TCP 位姿并非 `base` 坐标系会拒绝发送。

## 运动误差结果

发布目标后，工具至少等待 1 秒；TCP 连续 0.5 秒的位置变化小于 `0.2 mm` 时视为稳定。若持续运动或
未稳定，5 秒后仍会取当前 TCP 位姿计算结果并明确标记为超时取样。

终端输出包含实际相对位移 `[Δx, Δy, Δz]`、目标减实际的 XYZ 误差及其位置误差范数，单位均为 `mm`。
误差向量还以 `geometry_msgs/msg/Vector3Stamped` 发布在：

```text
/cartesian_impedance_controller/base_z_005_error
```

其中 `vector = target_position - actual_position`，坐标系为 `base`；正的 `z` 误差表示实际 Z 位移不足
`+0.05 m`。测量结果也会直接打印在执行该命令的终端。若上层需要订阅话题，应在运行测试命令前先启动订阅：

```bash
ros2 topic echo --once /cartesian_impedance_controller/base_z_005_error
```

执行前确认工作空间无人员、急停可用，并始终保持观察机械臂。
