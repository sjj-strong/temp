# 4. 参数与安全

所有六维数组使用 `[x, y, z, rx, ry, rz]` 顺序；关节力矩数组按 `joints` 顺序。

| 参数 | 作用 |
| --- | --- |
| `tf_prefix` | URDF 关节和坐标系名称的前缀。 |
| `base_frame` / `tip_frame` | KDL 链起点及控制末端；真机通常为 `base` / `tool0`。 |
| `target_topic` | 绝对目标位姿话题，默认 `~/target_pose`。 |
| `joints` | 六个关节名称，顺序必须与 KDL 链一致。 |
| `stiffness` | 六维比例增益；平移 N/m、旋转 Nm/rad。 |
| `damping` | 六维阻尼增益；平移 Ns/m、旋转 Nms/rad；作用于实测 $J\dot q$。 |
| `max_pose_error` | 每周期参与计算的位姿误差逐轴上限；平移 m、旋转 rad。它限制计算用误差，不限制绝对目标的可达距离。 |
| `max_wrench` | $K e_c-DJ\dot q$ 之后的任务 wrench 逐轴幅值上限；前三项 N、后三项 Nm。 |
| `max_torque` | 加入 Coriolis 后最终六个关节的力矩幅值上限，单位 Nm。 |
| `reference_filter_alpha` | 每周期一阶低通系数，范围 `[0,1]`；`0` 保持参考不变，`1` 直接使用目标。 |

增益和三层限幅必须为六个有限非负数，`reference_filter_alpha` 必须有限且位于 `[0,1]`。配置错误时控制器配置失败。Coriolis 固定启用，KDL 模型使用零重力向量。

本包另外提供低、中、高三档真机 K/D 参数文件；数值、共用限幅和使用方法见[刚度阻尼三档配置](07_刚度阻尼三档配置.md)。原有 `ur10e_ft300_cartesian_impedance.yaml` 保持独立，启动入口仍默认使用该文件。

控制器参数由本包 `config/` 提供。`ur10e_ft300_cartesian_impedance.yaml` 沿用原文件名，但控制律已不依赖 FT300；`ur10e_xbot_sim_cartesian_impedance.yaml` 用于仿真。是否启动 FT300 和夹爪由启动入口选择。

三层限幅只约束控制器输出。绝对目标可远于当前位姿，持续锁存后机器人仍会逐步向目标运动；运行前须确认目标、路径和 UR 控制柜的安全限制。`max_torque_rate` 已移除，因此力矩可能在相邻周期发生较大变化；首次测试应谨慎调低刚度和上限并现场监控。
