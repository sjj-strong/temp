# 4. 参数与安全

所有六维数组遵循 `[x, y, z, rx, ry, rz]` 顺序；前三项单位为 N 或 m/s 或 m，后三项单位为 Nm 或 rad/s 或 rad。

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `base_frame` / `tip_frame` | KDL 控制链起止坐标系 | `base_link` / `gripper_tcp` |
| `joints` | 关节名称，必须恰好 6 个 | UR 六关节 |
| `stiffness` | 位姿误差到 wrench 的逐轴增益 | `[100,100,100,10,10,10]` |
| `max_wrench` | 写入 UR 前的命令限幅 | `[40,40,40,4,4,4]` |
| `selection_vector` | Force Mode 顺从轴 | 全部 `true` |
| `speed_limits` | 顺从轴最大速度 | `[0.05,0.05,0.05,0.2,0.2,0.2]` |
| `deviation_limits` | 非顺从轴最大偏差 | `[0.01,0.01,0.01,0.1,0.1,0.1]` |
| `ur_damping` | UR Force Mode 阻尼 | `0.025` |
| `ur_gain_scaling` | UR Force Mode 增益缩放 | `0.5` |
| `use_external_ft` | 是否声明并使用外置 FT 状态接口 | `false` |
| `max_measured_wrench` | FT300 测量值硬安全阈值 | `[80,80,80,8,8,8]` |
| `force_feedback_gain` | 外力反馈修正增益 | `0.0` |

## 4.1 推荐调参顺序

1. `use_external_ft: false`，以很小的 `stiffness` 和 `max_wrench` 验证目标坐标系、TCP 和 Force Mode 方向。
2. 启用 FT300，但保持 `force_feedback_gain: 0.0`，确认传感器读数与已知外力一致。
3. 设置保守的 `max_measured_wrench`，并验证超限时控制器退出 Force Mode。
4. 逐步提高 `force_feedback_gain`；每次只调整一个轴，并持续观察振荡、速度和接触力。

## 4.2 当前实现边界

- 控制器没有直接关节力矩接口；底层闭环由 UR Force Mode 完成。
- `target_pose` 没有超时看门狗：最后一条有效目标会持续使用。上层必须在通信中断时停用控制器。
- FT300 读数目前未做软件低通滤波或自动零偏；应使用传感器驱动提供的归零流程，并在外部反馈增益为零时完成坐标/符号校验。
- 控制器测试覆盖插件加载、控制律限幅、wrench 坐标变换和超限判定；尚未替代实机低速接触验证。
