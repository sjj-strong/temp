# 4. 参数与安全

所有六维数组使用 `[x, y, z, rx, ry, rz]` 顺序。前三轴对应平移，后三轴对应旋转。

| 参数 | 含义 |
| --- | --- |
| `stiffness` | 六轴刚度：N/m、Nm/rad。 |
| `damping` | 六轴阻尼：Ns/m、Nms/rad；控制器直接使用 $J\dot q$，不以位姿差分估计速度。 |
| `integral_gain` / `integral_limit` | 可选积分项与逐轴 anti-windup 限制；默认 `integral_gain` 为零。若积分会加深已饱和的 wrench，则该轴暂停积分。 |
| `integral_reset_position_threshold` / `integral_reset_orientation_threshold` | 只有目标的平移或旋转跳变超过阈值才清零积分；重复发布同一目标不会清零。 |
| `max_wrench` | 映射到关节前的任务空间 wrench 硬上限。 |
| `max_torque` | 每关节力矩硬上限。 |
| `max_torque_rate` | 每关节力矩变化率上限，单位 Nm/s。 |
| `linear_reference_speed` / `angular_reference_speed` | 目标位姿内部参考生成器的最大平移/旋转速度。 |
| `reference_filter_alpha` | 每控制周期的一阶低通系数，范围 `[0, 1]`；`0` 保持当前参考，`1` 关闭滤波。目标永久锁存直到新目标覆盖。 |
| `use_coriolis` | 是否加入零重力 KDL 模型的 $C(q,\dot q)$；不包含重力项。 |
| `workspace_min` / `workspace_max` | 当前 TCP 的 x/y/z 工作空间边界。 |
| `joint_position_min` / `joint_position_max` | 六关节安全位置边界。 |
| `use_external_ft` | 是否请求 FT300 状态接口。 |
| `max_measured_wrench` | FT300 统一至 `base_frame` 后的硬安全阈值。 |

所有 K/D/Ki、速度和限幅参数必须为有限数值；限幅和速度必须非负，`reference_filter_alpha` 必须在 `[0, 1]`。无效配置会使控制器配置失败。

当前 `ur10e_ft300_cartesian_impedance.yaml` 的平移起步值为 `stiffness=500 N/m`、`damping=40 Ns/m`。
因此 10 mm 静态平移误差约对应 5 N 弹簧力；旋转刚度、滤波参数、积分项与各类力矩限制未因此调整。

## 4.1 配置文件归属

控制器的全部参数只能由本包的 `config/` 文件定义。当前提供：

- `ur10e_ft300_cartesian_impedance.yaml`：UR10e + FT300 真机配置，使用 `base → tool0`。
- `ur10e_xbot_sim_cartesian_impedance.yaml`：XBot 仿真配置，使用仿真组合 URDF 的 `base_link → tool0`。

`ur_teleop` 只负责选择上述配置并发布目标，不覆盖阻抗参数。若需要调节刚度、阻尼、滤波或任一安全限制，应修改对应的本包配置文件。

## 4.2 必须保留的保护顺序

1. 限制目标参考的平移和旋转变化。
2. 限制 Cartesian wrench。
3. 通过 $J^T$ 映射并可选加入 $C(q,\dot q)$。
4. 限制绝对关节力矩，再限制每周期力矩变化，最后再次保证绝对上限。
5. 状态、运动学、动力学、工作空间、关节边界或 FT300 检查失败时写零力矩。

## 4.3 实机调参顺序

1. 关闭 FT300、`integral_gain` 保持零、`use_coriolis: false`，使用很小的 K/D 和严格 torque-rate 上限验证坐标方向。
2. 在无接触空间逐步增加 D，确认无高频振荡后再增加 K。
3. 启用 `use_coriolis` 并保持 UR 内部重力补偿；不得加入软件重力项。
4. 激活并标定官方摩擦补偿控制器。
5. 最后启用 FT300 保护，设置低于机械系统风险阈值的 `max_measured_wrench`。

本软件的限幅不替代 UR 安全配置、机械限位、急停和经过批准的实机风险评估。
