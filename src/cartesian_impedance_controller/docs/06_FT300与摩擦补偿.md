# 6. FT300 与摩擦补偿

当前简化版笛卡尔阻抗控制器只读取六个关节的位置和速度，不订阅或请求 FT300 的 wrench 状态，也不使用 `max_measured_wrench`。启动入口可选择是否连接真实 FT300；此选择只影响传感器硬件和相应发布，不改变控制律。关闭 FT300 时不访问其串口。

FT300 若由其他节点使用，应单独完成设备归零、坐标系校验、数据新鲜度检查和安全策略。当前控制器的三层限幅不能代替外部接触监测。组合 URDF 保留 FT300 的连杆和 TF，控制末端仍为 UR 原始 `tool0`。

官方 `friction_model_controller` 独占 `friction_model/viscous_*`、`friction_model/coulomb_*` 等接口；本控制器只独占六个关节 `effort` 接口。UR 控制柜负责内部重力补偿，本控制器只添加零重力 KDL 模型的 Coriolis 项，不添加软件摩擦或重力项。
