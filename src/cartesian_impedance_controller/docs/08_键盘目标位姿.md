# 键盘发布笛卡尔目标位姿

脚本 `src/keyboard_target_pose.py` 订阅 `/tcp_pose_broadcaster/pose`，从当前 TCP 位姿生成目标，并向
`/cartesian_impedance_controller/target_pose` 发布 `geometry_msgs/msg/PoseStamped`。仅改变 `base` 坐标系中的
XYZ 平移，保持收到的 TCP 姿态。控制器必须已激活，且示教器急停可用；首次实机使用前按本包
`docs/03_使用方式.md` 核对 payload、参数和工作空间。

```bash
source /opt/ros/jazzy/setup.bash
source /ros2_ws/install/setup.bash
ros2 control list_controllers -c /controller_manager
/usr/bin/python3 /ros2_ws/src/cartesian_impedance_controller/src/keyboard_target_pose.py
```

| 按键 | 操作 |
| --- | --- |
| `W` / `S` | base X 正向 / 负向 |
| `D` / `A` | base Y 正向 / 负向 |
| `R` / `F` | base Z 正向 / 负向 |
| 空格 | 将当前 TCP 位姿设为保持目标 |
| `Q` 或 `Ctrl+C` | 退出脚本，控制器继续保持最后收到的目标 |

默认每次按键移动目标 5 mm；目标到当前 TCP 的距离不得超过 30 mm。没有新鲜的位姿、位姿坐标系与
`base` 不符，或目标话题没有订阅者时，脚本拒绝发布。按键目标会被控制器锁存；松开按键并不会取消
目标。空格会发布当前 TCP 位姿作为新的保持目标；退出脚本不会停用控制器或触发急停。

可用 `--step 0.002` 设置单步位移（最大 0.01 m），用 `--max-lead 0.02` 设置目标与实际 TCP 的最大
距离（最大 0.05 m）。如果使用带前缀的 base frame，可通过 `--frame` 指定；话题可通过
`--pose-topic` 和 `--target-topic` 指定。脚本需要交互式终端，不能通过管道输入按键。
本工作区的虚拟环境可能不包含 ROS Python 依赖，因此示例明确使用系统解释器 `/usr/bin/python3`。
