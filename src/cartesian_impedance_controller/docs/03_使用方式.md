# 3. 使用方式

## 3.1 构建与加载

```bash
cd /ros2_ws
source /opt/ros/jazzy/setup.bash
colcon build --packages-select cartesian_impedance_controller
source install/setup.bash

ros2 run controller_manager spawner cartesian_impedance_controller \
  --param-file "$(ros2 pkg prefix cartesian_impedance_controller)/share/cartesian_impedance_controller/config/ur10e_ft300_cartesian_impedance.yaml"
```

控制器通过 `ControllerInterfaceBase::get_robot_description()` 获得 URDF；不需要、也不应在本控制器 YAML 中复制 `robot_description`。

## 3.2 切换到直接力矩控制

先确认官方摩擦补偿控制器处于 active：

```bash
ros2 control list_controllers
```

然后停用当前运动控制器并激活本控制器。实际名称按系统已加载控制器调整；`force_mode_controller` 不得同时 active。

```bash
ros2 control switch_controllers \
  --deactivate joint_trajectory_controller \
  --activate cartesian_impedance_controller \
  --strict
```

停用时执行反向切换。控制器停用和任何内部安全错误都会写入零关节力矩。

## 3.3 配置官方摩擦补偿

摩擦补偿只在 direct torque 模式生效。以下示例启用 UR 内部的全额粘性和库仑补偿；必须先在低风险条件下完成实机验证。

```bash
ros2 service call /friction_model_controller/set_friction_model_parameters \
  ur_msgs/srv/SetFrictionModelParameters \
  "{parameters: {viscous_scale: [1, 1, 1, 1, 1, 1], coulomb_scale: [1, 1, 1, 1, 1, 1]}}"
```

不要在本控制器内叠加额外摩擦力矩，也不要发送重力补偿。

## 3.4 发布目标位姿

默认话题为 `/cartesian_impedance_controller/target_pose`，类型是 `geometry_msgs/msg/PoseStamped`。`header.frame_id` 必须为空或等于 `base_link`（有 `tf_prefix` 时使用前缀后的 frame）；控制器不会在实时循环查询 TF。

```bash
ros2 topic pub --rate 20 /cartesian_impedance_controller/target_pose \
  geometry_msgs/msg/PoseStamped \
  "{header: {frame_id: base_link}, pose: {position: {x: 0.45, y: 0.0, z: 0.35}, orientation: {x: 0.0, y: 0.0, z: 0.0, w: 1.0}}}"
```

目标在内部执行线速度和角速度限制。若超过 `command_timeout` 未收到有效目标，控制器锁存超时瞬间的当前 TCP 位姿并保持。

## 3.5 FT300 可选模式

无外置传感器时设置：

```yaml
use_external_ft: false
```

启用 FT300 时检查 `ft_sensor_name` 和 `ft_frame` 与 URDF 中的名称完全一致。传感器仅参与安全保护；其超限会使控制器立即写入零关节力矩并返回错误。
