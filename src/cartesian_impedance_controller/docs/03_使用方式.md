# 3. 使用方式

## 3.1 构建

```bash
cd /ros2_ws
source /opt/ros/jazzy/setup.bash
colcon build --packages-select cartesian_impedance_controller
source install/setup.bash
```

## 3.2 启动前检查

1. 使用 `ur10e_robotiq_ft.urdf.xacro` 启动机器人描述与 ros2_control；若使用 FT300，设置 `ft_sensor_use_fake_mode:=false` 并确认驱动连接成功。
2. controller manager 的参数中载入本包的 `config/ur10e_ft300_cartesian_impedance.yaml`。
3. 确认 `force_mode_controller` 未处于 active 状态。
4. 确认 `base_link`、`gripper_tcp` 与 `robotiq_ft_frame_id` 与实际装配一致。

使用 controller manager 的 spawner 加载示例：

```bash
ros2 run controller_manager spawner cartesian_impedance_controller \
  --param-file "$(ros2 pkg prefix cartesian_impedance_controller)/share/cartesian_impedance_controller/config/ur10e_ft300_cartesian_impedance.yaml"
```

实际系统若 controller manager 位于命名空间中，加入相应的 `--controller-manager /<namespace>/controller_manager`。

## 3.3 无外置传感器运行

将参数设为：

```yaml
use_external_ft: false
```

此时控制器只请求六个关节位置状态接口，不会请求 `robotiq_ft_sensor/*`。位姿误差仍会转换为 UR Force Mode wrench。

## 3.4 使用 FT300 运行

```yaml
use_external_ft: true
ft_sensor_name: robotiq_ft_sensor
ft_frame: robotiq_ft_frame_id
force_feedback_gain: 0.0
```

先保持 `force_feedback_gain: 0.0`，观察广播器输出的实际力方向。使用已知单轴外力验证 `robotiq_ft_frame_id` 方向和符号后，再以很小的增量提高该增益。

## 3.5 发布目标位姿

默认私有话题 `~/target_pose` 在控制器实例名为 `cartesian_impedance_controller` 时解析为：

```text
/cartesian_impedance_controller/target_pose
```

消息类型为 `geometry_msgs/msg/PoseStamped`，`header.frame_id` 必须为空或为 `base_link`；四元数必须有效。

```bash
ros2 topic pub --rate 20 /cartesian_impedance_controller/target_pose \
  geometry_msgs/msg/PoseStamped \
  "{header: {frame_id: base_link}, pose: {position: {x: 0.45, y: 0.0, z: 0.35}, orientation: {x: 0.0, y: 0.0, z: 0.0, w: 1.0}}}"
```

先在无接触、低刚度条件下发布接近当前 TCP 的目标位姿。停止时停用控制器；其 `on_deactivate()` 会请求 UR 结束 Force Mode。
