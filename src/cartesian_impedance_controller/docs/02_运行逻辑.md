# 2. 运行逻辑

```text
绝对 PoseStamped 目标 → 合法性检查 → 锁存 → 一阶低通 → 位姿误差 → max_pose_error
                                                        ↓
关节位置/速度 → FK、J(q) → 实测速度 J(q)dq → K·e - D·Jdq → max_wrench
                                                        ↓
                                      JᵀF + C(q,dq) → max_torque → 六轴 effort
```

## 2.1 坐标系和目标

- 真机配置使用 `base → tool0`，仿真配置使用 `base_link → tool0`。FK 和 Jacobian 使用同一条 KDL 链。
- Jacobian 的参考点是 `tool0` 原点，六行顺序为 `[v_x, v_y, v_z, ω_x, ω_y, ω_z]`，均在基坐标系表达。
- 平移误差为目标减当前；旋转误差由 `R_target R_currentᵀ` 的旋转向量给出。
- 只接受空 `header.frame_id` 或配置的 `base_frame`；位置必须有限，四元数必须有效。目标是绝对位姿，不是相对位移，也没有 workspace 范围检查。
- `/cartesian_impedance_controller/current_pose` 使用相同 KDL 链发布当前 `tool0` 位姿。

## 2.2 参考滤波和三层限幅

`reference_filter_alpha` 每周期对已锁存的绝对目标做一阶低通：平移线性插值，姿态四元数 slerp。`0` 保持当前参考，`1` 直接采用目标。滤波后计算误差；不生成目标速度，也不对参考位姿施加速度限制。

1. 将六维位姿误差按 `max_pose_error` 逐轴裁剪；前三项单位 m，后三项单位 rad。
2. 用 $F=K e_c-DJ(q)\dot q$ 计算任务 wrench，然后按 `max_wrench` 逐轴裁剪。
3. 用 $\tau=J(q)^TF+C(q,\dot q)$ 计算关节力矩，然后按 `max_torque` 逐轴裁剪。Coriolis 始终启用；不添加软件重力项。

控制器不包含积分、力矩变化率限制、workspace 检查、关节位置检查或 FT300 超限保护。状态无效、运动学/动力学计算失败、结果非有限或接口写入失败时，写入零力矩并返回错误。控制器参数见 [`04_参数与安全.md`](04_参数与安全.md)。
