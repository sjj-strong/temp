# 1. 控制器概览

`cartesian_impedance_controller` 是面向 Universal Robots ROS 2 Driver 的笛卡尔柔顺控制器。它使用 UR 的 Force Mode 专用接口执行控制，不输出关节力矩，也不占用关节位置命令接口。

控制器订阅实时目标末端位姿，基于实际 TCP 位姿计算六维位姿误差，将误差乘以逐轴刚度并限幅为期望 wrench，再写入 UR `force_mode/*` 接口。UR 控制柜的 Force Mode 负责底层运动执行。

## 1.1 适用对象

- UR10e 或其他由 Universal Robots ROS 2 Driver 驱动、提供 `force_mode/*` 接口的机器人。
- TCP 位于 `robot_description` 中，默认使用 `gripper_tcp`。
- 可选 Robotiq FT300 外置传感器；关闭外置传感器后，控制器仍可运行。

## 1.2 控制器插件

```yaml
type: cartesian_impedance_controller/CartesianImpedanceController
```

完整示例参数文件位于 `config/ur10e_ft300_cartesian_impedance.yaml`。

## 1.3 前置条件与互斥关系

- controller manager 必须向控制器节点提供 `robot_description` 参数。
- `base_frame` 到 `tip_frame` 必须在 URDF 中构成有效 KDL 链。
- 激活本控制器时，必须停用官方 `ur_controllers/ForceModeController`；两者会争用同一组 `force_mode/*` 命令接口。
- 这是面向 Force Mode 的控制器，实机第一次运行必须使用低刚度、低速度、低 wrench 限幅，并保证急停可用。
