# 5. 直接力矩运行逻辑

## 5.1 激活

控制器激活时读取 $q_0$，计算当前 TCP 位姿 $T_0$，并同时设为内部参考和超时保持位姿。积分状态及上一周期力矩清零，因此不会因为历史目标在激活瞬间产生跳变。

## 5.2 实时循环

```text
q, qdot ──► FK ──► 当前 TCP ─┐
       └──► J(q) ─► J(q)qdot ├─► 6D 阻抗 wrench ─► J(q)^T ─┐
目标 Pose ─► 实时缓冲 ─► 参考限速 ┘                         ├─► torque 限制 ─► effort
q, qdot ───────────────────────────────► C(q,qdot), gravity=0 ┘
FT300（可选）─► base_frame wrench ─► 超限保护
```

每个周期执行：

1. 读取关节位置和速度，验证关节/工作空间边界，并计算当前 TCP 位姿与 $J(q)$。
2. 从 `RealtimeBuffer` 读取最近目标；目标不新鲜时锁存当前位姿作为保持目标。
3. 以最大线速度和角速度推进内部参考，计算平移误差和 SO(3) 对数姿态误差。
4. 用 $J(q)\dot q$ 作为测量末端速度，并由相邻限速参考得到期望 twist，计算 K/D/Ki 六维 wrench；积分项按 `dt` 更新、限幅，且不会加深已饱和的 wrench。
5. 先限制 wrench，再计算 $J^T F$；可选加入由零重力 KDL 模型计算的 $C(q,\dot q)$。
6. 应用关节绝对力矩和变化率限制，写入六个 `effort` 命令接口。

FT300 不会改变第 4 步的控制律。启用时，传感器 wrench 依据当前 `base_frame → ft_frame` KDL 变换统一坐标系；任何无效数据或超限都会进入零力矩故障路径。

## 5.3 故障与停用

下列任一情况会写入全部六轴零力矩并返回控制错误：状态无效、FK/Jacobian/Coriolis 计算失败、关节或工作空间越界、FT300 无效或超限、命令接口写入失败。停用控制器时同样清零命令和内部积分/限幅状态。
