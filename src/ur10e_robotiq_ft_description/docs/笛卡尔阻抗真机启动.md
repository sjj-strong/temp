# 笛卡尔阻抗真机启动

`real_bringup.launch.py` 默认会在真机驱动就绪后加载并激活
`cartesian_impedance_controller`。官方 `scaled_joint_trajectory_controller` 会保持
inactive，因而不会与笛卡尔阻抗控制器争用关节命令接口。

```bash
ros2 launch ur10e_robotiq_ft_description real_bringup.launch.py \
  robot_ip:=169.254.138.15 \
  ft_sensor_ftdi_id:=ttyUSB2 \
  gripper_com_port:=/dev/ttyUSB0
```

启动完成后验证：

```bash
ros2 control list_controllers -c /controller_manager
```

预期 `cartesian_impedance_controller` 是 `active`，
`scaled_joint_trajectory_controller` 是 `inactive`。

如需原来的官方启动方式，使用：

```bash
ros2 launch ur10e_robotiq_ft_description real_bringup.launch.py \
  use_cartesian_impedance:=false
```

固定 Z 轴 `+0.05 m` 单次测试命令见
`cartesian_impedance_controller/docs/07_固定Z轴测试命令.md`。执行前请确认工作空间、
UR payload、保护停止和急停均已就绪。
