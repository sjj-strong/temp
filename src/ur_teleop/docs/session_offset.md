# Alicia 会话偏移

每次启动遥操作，先验证双臂 Home，再等待静止，随后自动记录双方实际位置作为本次映射基准。无需手动设置偏移。

| 参数 | 作用 |
| --- | --- |
| `home.at_home_tolerance_rad` | 双臂实际位置与配置 Home 的最大逐关节误差，rad |
| `home.settle_time_s` | 捕获前需要连续静止的时间，秒 |
| `home.settle_motion_threshold_rad` | 判定静止的逐周期关节变化阈值，rad |

捕获值只在本次运行中有效，不修改配置文件。主臂回到捕获位置时，UR 目标也回到捕获的从臂位置。运行中不自动重新捕获；需要新基准时，重新回 Home 并重启遥操作。

长期等待静止时检查主从臂是否仍在运动、反馈是否稳定。启动步骤见[完整流程](workflow.md)，映射规则见[关节映射](joint_mapper.md)。
