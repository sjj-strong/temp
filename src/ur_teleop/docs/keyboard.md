# 键盘操作

| 场景 | 按键 | 功能 |
| --- | --- | --- |
| 真机 Home | Enter | 确认示教器已运行 External Control，随后执行 Home |
| Alicia 遥操作 | Enter | 提示就绪后开始遥操作 |
| Alicia 采集 | Enter | 开始一段 |
| Alicia 采集 | S | 保存当前段 |
| Alicia 采集 | D | 丢弃当前段 |
| Alicia 采集 | Q | 保存当前段并结束采集 |
| 所有终端 | Ctrl-C | 退出当前进程 |

在对应启动终端操作。采集单键无需额外回车；不要让多个等待键盘输入的进程共用同一终端。Xbot 采集使用手柄，见[采集操作](data_recorder.md#操作)。

程序优先读取 `/dev/tty`，退出后恢复终端模式。按键无响应时检查终端是否有交互输入，避免通过无终端的后台任务运行需要键盘操作的进程。
